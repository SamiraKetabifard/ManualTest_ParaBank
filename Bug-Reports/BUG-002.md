# BUG-002 — State Field Accepts Numeric Input

## Summary

The State field accepts numeric-only values during registration.

## Feature

Registration

## Bug Type

Functional / Input Validation

## Severity

Medium

## Priority

Medium

## Steps to Reproduce

1. Open the Registration page.
2. Enter `425` in the State field.
3. Complete the remaining required fields.
4. Submit the registration form.

## Expected Result

The State field should reject numeric-only input.

## Actual Result

The State field accepts `425`.
