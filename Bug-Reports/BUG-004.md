# BUG-004 — Transfer to the Same Account Is Accepted

## Summary

The Transfer Funds feature allows a user to select the same account as both the source and destination account.

## Feature

Transfer Funds

## Bug Type

Functional / Business Logic

## Severity

High

## Priority

High

## Preconditions

User is logged in and has an active account.

## Test Data

Amount: `$1500`  
From Account: `13788`  
To Account: `13788`

## Steps to Reproduce

1. Login to ParaBank.
2. Open Transfer Funds.
3. Enter `$1500` as the transfer amount.
4. Select account `13788` as the source account.
5. Select account `13788` as the destination account.
6. Submit the transfer.

## Expected Result

The system should prevent transfers where the source and destination accounts are identical.

## Actual Result

The system accepts the transaction and displays:

`Transfer Complete!`

`$1500.00 has been transferred from account #13788 to account #13788.`

## Impact

The application does not enforce a basic business rule preventing a transfer from an account to itself.
