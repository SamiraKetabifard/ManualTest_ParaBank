# BUG-006 — Zero Loan Amount Causes Internal Error

## Summary

Entering a zero loan amount causes an internal error instead of a validation message.

## Feature

Request Loan

## Bug Type

Functional / Input Validation / Error Handling

## Severity

Medium

## Priority

High

## Test Data

Loan Amount: `0000`

## Steps to Reproduce

1. Login to ParaBank.
2. Open Request Loan.
3. Enter `0000` as the Loan Amount.
4. Submit the loan request.

## Expected Result

The system should reject a zero loan amount and display a clear validation message.

## Actual Result

The system displays:

`Error! An internal error has occurred and has been logged.`
