# BUG-003 — Zip Code Field Accepts Alphabetic Input

## Summary

The Zip Code field accepts alphabetic characters.

## Feature

Registration

## Bug Type

Functional / Input Validation

## Severity

Medium

## Priority

Medium

## Test Data

Zip Code: `jjgk`

## Steps to Reproduce

1. Open the Registration page.
2. Enter `jjgk` in the Zip Code field.
3. Complete the remaining required fields.
4. Submit the registration form.

## Expected Result

The Zip Code field should reject alphabetic input.

## Actual Result

The Zip Code field accepts `jjgk`.
