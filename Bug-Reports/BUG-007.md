# BUG-007 — Bill Payment Displays Internal Error for Invalid or Excessive Amount

## Summary

An invalid or excessive bill payment amount results in a generic internal error instead of an appropriate validation message.

## Feature

Bill Payment

## Bug Type

Functional / Business Logic / Error Handling

## Severity

Medium

## Priority

High

## Steps to Reproduce

1. Login to ParaBank.
2. Open Bill Pay.
3. Enter valid payee information.
4. Enter the required account information.
5. Enter an invalid or excessive payment amount.
6. Submit the payment.

## Expected Result

The system should reject the transaction and display a meaningful validation or insufficient-funds message.

## Actual Result

The system displays:

`Error! An internal error has occurred and has been logged.`
