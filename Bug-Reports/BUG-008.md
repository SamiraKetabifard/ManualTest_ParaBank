# BUG-008 — Profile Update Confirmation Message Does Not Match Updated Information

## Summary

The profile update confirmation message does not accurately describe the information changed by the user.

## Feature

Update Contact Information

## Bug Type

UI / Functional

## Severity

Low

## Priority

Medium

## Steps to Reproduce

1. Login to ParaBank.
2. Open Update Contact Info.
3. Change the Last Name.
4. Submit the form.
5. Review the confirmation message.

## Expected Result

The confirmation message should accurately describe the information that was updated.

## Actual Result

The system displays:

`Profile Updated`

`Your updated address and phone number have been added to the system.`

The message does not accurately describe the Last Name update.

Open
