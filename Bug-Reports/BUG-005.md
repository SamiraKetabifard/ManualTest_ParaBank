# BUG-005 — Transfer Can Result in a Negative Account Balance

## Summary

The Transfer Funds feature allows a transfer that can reduce the source account balance below zero.

## Feature

Transfer Funds

## Bug Type

Functional / Business Logic

## Severity

High

## Priority

High

## Preconditions

User has an account with an available balance lower than the requested transfer amount.

## Steps to Reproduce

1. Login to ParaBank.
2. Open Transfer Funds.
3. Enter an amount greater than the available balance.
4. Select the source account.
5. Select a different destination account.
6. Submit the transfer.
7. Open Accounts Overview.
8. Review the source account balance.

## Expected Result

The transfer should be rejected when the available balance is insufficient, unless overdraft functionality is explicitly supported.

## Actual Result

The transfer was accepted and the source account could become negative.

## Impact

The application may allow a user to transfer more funds than are available in the source account.
