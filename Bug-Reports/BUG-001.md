# BUG-001 — City Field Accepts Numeric Input

## Summary

The City field accepts numeric-only values during user registration.

## Feature

Registration

## Bug Type

Functional / Input Validation

## Severity

Medium

## Priority

Medium

## Environment

- Application: ParaBank
- OS: Windows
- Browser: Google Chrome
- Testing Type: Manual Exploratory Testing

## Preconditions

Registration page is accessible.

## Test Data

City: `455`

## Steps to Reproduce

1. Open the Registration page.
2. Enter `455` in the City field.
3. Complete the remaining required fields.
4. Submit the registration form.

## Expected Result

The City field should reject numeric-only input and display an appropriate validation message.

## Actual Result

The City field accepts `455`.
