# ParaBank Manual QA Testing Project

## Project Overview

This project contains manual testing activities performed on the ParaBank web application.

The testing was conducted using an Exploratory Testing approach. The application was explored feature by feature, followed by the creation and execution of manual test cases based on the observed functionality.

The project focuses on functional testing, negative testing, input validation, boundary value testing, business logic testing, UI testing, smoke testing, and basic security-related observations.

## Testing Approach

- Exploratory Testing
- Functional Testing
- Smoke Testing
- Positive Testing
- Negative Testing
- Input Validation Testing
- Boundary Value Testing
- Business Logic Testing
- UI Testing
- Basic Security Testing
