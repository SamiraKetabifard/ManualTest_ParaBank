# Administration Test Cases

## TC-ADMIN-001 — Administration Information

**Type:** Functional / Smoke

### Steps

1. Open the Administration page.
2. Review the available services and configuration information.

### Expected Result

Administration information and available service/data access options should be displayed correctly.

### Actual Result

The page displayed:

- JMS Service
- Data Access Mode
- SOAP
- REST XML
- REST JSON
- JDBC
- WSDL
- WADL
- OpenAPI
- Application Settings
