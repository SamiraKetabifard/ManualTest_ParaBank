# Contact Information Test Cases

## TC-CONTACT-001 — Update Contact Information

**Type:** Functional / UI

### Steps

1. Open Update Contact Info.
2. Modify the Last Name.
3. Submit the form.
4. Observe the confirmation message.

### Expected Result

The updated information should be saved and the confirmation message should accurately describe the updated information.

### Actual Result

The system displayed:

`Profile Updated`

`Your updated address and phone number have been added to the system.`

The message did not accurately describe the information that was changed.

### Status

FAIL
